Privacy Policy

This privacy policy applies to the personal use of CarotDAV Google Drive Access.

Google User Data

This application uses Google OAuth 2.0 to access the user's own Google Drive account.

The application may access files, folders, file names, metadata, and other Google Drive information necessary to provide the requested file access and management functions.

Use of Data

Google user data is used solely to access and manage the user's Google Drive as requested by the user.

Data Sharing

Google user data is not sold, rented, or shared with third parties.

Data Storage

OAuth authentication credentials are stored locally on the user's computer as required by CarotDAV. The application does not operate a server that stores the user's Google Drive files.

Data Retention

Authentication credentials remain on the user's computer until they are deleted or access is revoked.

Revoking Access

The user can revoke this application's access to Google Drive through their Google Account security settings.

Contact

This application is for personal use by its owner.
